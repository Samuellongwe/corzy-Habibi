# Cozy Habibi — Sales Demo

This is a front-end sales prototype for Cozy Restaurant & Lounge, Lusaka.

## Run it
Open `index.html` in Chrome/Edge.

## What works
- Responsive premium restaurant landing page
- Menu filtering
- Add-to-cart
- Persistent cart using localStorage
- WhatsApp order generation
- Table QR demo interaction
- Loyalty club demo
- Reservation request via WhatsApp
- Mobile-first responsive layout

## Important
Menu prices in this prototype are deliberately marked as DEMO placeholders. Replace them with Cozy's approved current prices before presenting it as a production ordering system.
